# Cómo contribuir

¡Gracias por querer colaborar!

1. Haz un fork del repositorio.
2. Crea una rama a partir de `develop`: `git checkout -b feature/mi-mejora`.
3. Haz tus cambios con commits de mensaje claro.
4. Sube la rama y abre una Pull Request hacia `develop`.

El código debe estar en Python y con docstrings en todas las funciones.
