# Gestor de tareas

Aplicación de consola en Python para gestionar tareas, con persistencia en JSON
y documentación generada automáticamente con GitHub Actions.

## Instalación

    git clone https://github.com/TU_USUARIO/gestor-tareas-actions.git
    cd gestor-tareas-actions
    python main.py

## Documentación

Consulta la carpeta `docs/` para más información.
